# Sistema-de-Conversi-n-de-Medidas-profesional
Este es un conversor de unidades de grado profesional desarrollado en una única página (SPA). Utiliza un enfoque basado en datos (Data-Driven) donde las unidades y sus factores de conversión se almacenan en estructuras de datos de JavaScript, lo que permite agregar nuevas métricas fácilmente sin alterar la lógica principal.
